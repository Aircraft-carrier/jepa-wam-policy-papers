# Repository Skills

这些 skill 是本仓库的 Codex 工作说明，放在仓库内便于随项目一起版本管理。

## Skills

- [`paper-literature-review`](paper-literature-review/SKILL.md)：JEPA、DINO、V-JEPA、I-JEPA、WAM 和机器人策略论文的检索、证据核验、对比分析和卡片写作。
- [`add-paper`](add-paper/SKILL.md)：新增一篇论文时，从身份去重、Markdown 卡片、总表/矩阵/BibTeX 同步，到 HTML 网站生成和验证的完整流程。

推荐使用方式：新增论文时先阅读 `add-paper/SKILL.md`，需要判断研究证据或比较实验公平性时再阅读 `paper-literature-review/SKILL.md` 及其模板。
